# raw/: immutable sources

Put source files here: datasheets, captured `--log` dumps, HID descriptors, pasted notes.

To fold one into the wiki: summarize it into a page under `../wiki/`, cross-link it, add it to `../wiki/index.md` under **Sources**, and add an `ingest` line to `../log.md`.

**Never modify the files in this folder.** They are the original records.
